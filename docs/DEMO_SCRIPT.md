# 示範影片與驗收腳本

## 錄影前準備

- [ ] 板子以 USB 接上電腦，已燒錄 `voice_led` 韌體
- [ ] 已關閉 VS Code 序列埠監控視窗
- [ ] 已執行 **Voice LED: Web UI**，Chrome 開啟 `http://localhost:8000`，右上角顯示「已連線」
- [ ] 已勾選「語音回覆」，喇叭音量已打開
- [ ] 辨識語言設為「中文（台灣）」
- [ ] 已在「執行紀錄」按下「清除」
- [ ] 按下「全部關燈」，讓兩顆燈從熄滅開始
- [ ] 手機可以同時拍到**電腦螢幕**與**板子上的燈**

## 腳本

每一步都用語音操作：按麥克風按鈕或空白鍵，然後說出「說出的話」欄位的內容。

| # | 項目 | 說出的話 | 預期：網頁 | 預期：板子 LED | 預期：語音回覆 |
|---|---|---|---|---|---|
| 1 | 左邊開燈 | 左邊開燈 | 辨識「左邊開燈」→ `BLUE_ON` 板子已確認執行 | 藍燈亮 | 好的，左邊開燈 |
| 2 | 左邊關燈 | 左邊關燈 | `BLUE_OFF` 板子已確認執行 | 藍燈滅 | 好的，左邊關燈 |
| 3 | 右邊開燈 | 右邊開燈 | `GREEN_ON` 板子已確認執行 | 綠燈亮 | 好的，右邊開燈 |
| 4 | 右邊關燈 | 右邊關燈 | `GREEN_OFF` 板子已確認執行 | 綠燈滅 | 好的，右邊關燈 |
| 5 | 閃爍三次（加分） | 閃爍三次 | `BLINK_ALL` 板子已確認執行，網頁燈號閃動 | 兩燈一起閃三次後恢復 | 好的，兩燈閃爍三次 |
| 6 | 非控制語句 | 今天天氣很好 | 黃色「未執行：非控制指令，LED 狀態不變」 | **不變** | 這不是控制指令，燈號維持不變 |
| 7 | 英文指令（加分） | 先把語言切換成 **English (US)**，說 **turn on the left light** | 辨識「turn on the left light」→ `BLUE_ON` | 藍燈亮 | OK, done.（英文回覆） |
| 8 | 通訊中斷 | 語言切回中文，**拔掉 USB 線**，再說「右邊開燈」 | 右上角變紅「通訊中斷」，LED 狀態「未知」，執行情形「通訊失敗，指令未送達」 | 不動作（板子已斷電） | 通訊失敗，請檢查開發板連線 |
| 9 | 恢復連線 | 插回 USB 線，等幾秒後按「連線開發板」並選擇 COM 埠（不用說話） | 恢復「已連線」，LED 狀態恢復顯示 | — | — |

第 7 步若 left light 一直被聽成 flashlight，可改說 **turn on the blue light**。

第 1 到 8 步都有語音回覆，影片中聽得到就代表「語音回覆」加分項目已經示範到了。

## 錄完之後

1. 在「執行紀錄」按 **「匯出 CSV」**，存成驗收紀錄
2. 將結果填入 `docs/REPORT.md` 第八節
3. 影片上傳 YouTube（可設為「不公開」），連結填入報告

## 旁白參考（可選）

> 這是用 Vibe Coding 完成的 AMB82-MINI 語音控制 LED 系統。瀏覽器透過 Web Speech API 辨識語音，將文字解析成指令後，經由 USB 序列埠傳給開發板；開發板控制 D23 藍燈、D24 綠燈，並回傳 JSON 狀態，網頁上的燈號就是根據這份回報顯示的。
